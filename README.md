# 复制 Obsidian 选区在文件中的位置

# 1、功能概览

- 在编辑模式（源码模式 / 实时预览）下，把当前选区所在文件与行号按配置格式复制到剪贴板。
- 典型输出：`/Users/xx/目录/笔记.md#L77-81`，可直接粘贴给 Claude Code、VS Code 等工具定位。
- 仅支持桌面端（移动端拿不到绝对路径）。

# 2、入口

- **命令面板：** 「复制选区位置」，不设默认热键，可在「设置 → 快捷键」中绑定（如 `Opt+Cmd+C`）。
- **编辑器右键菜单：** 「复制位置」。
- 阅读模式下拿不到行号，命令不可用，右键菜单也不展示。

# 3、取行规则

- **有选区：** 取选区起止行，单行输出 `#L77`，多行输出 `#L77-81`。
    - 选区末尾落在下一行行首（如三击整行）时，末行退回上一行。
- **无选区：** 取光标所在行，输出 `#L77`。
- **多个选区：** 每个选区一行，按行号升序以换行拼接；格式不含行号时重复行只保留一行。
- **行号口径：** 文件原始行号，frontmatter 计入。

# 4、输出格式

| 格式 | 示例 |
| :--- | :--- |
| 绝对路径+行号（默认） | `/Users/xx/目录/笔记.md#L77-81` |
| 仅绝对路径 | `/Users/xx/目录/笔记.md` |
| 库内路径+行号 | `目录/笔记.md#L77-81` |
| 仅库内路径 | `目录/笔记.md` |
| Obsidian 链接 | `obsidian://open?vault=xx&file=xx`（URL 编码） |
| Wiki 链接 | `[[笔记#标题]]`，标题取选区起始行之前最近的一个，没有时为 `[[笔记]]` |
| 自定义模板 | 按模板输出，默认 `{absPath}#L{range}` |

- **自定义模板变量：**
    - `{absPath}`：绝对路径
    - `{relPath}`：库内相对路径
    - `{vaultName}`：库名
    - `{fileName}` / `{basename}`：带 / 不带扩展名的文件名
    - `{start}` / `{end}`：起始行 / 结束行
    - `{range}`：单行为 `77`，多行为 `77-81`
    - `{heading}`：选区起始行之前最近的标题
    - 未知变量原样保留。
- **复制成功提示：** 默认开启，可在设置中关闭。

# 5、构建与安装

- 安装依赖：`npm install`
- 构建并安装到仓库：`npm run deploy`，默认仓库为 `/path/to/vault`，可通过环境变量 `OBSIDIAN_VAULT` 覆盖。
